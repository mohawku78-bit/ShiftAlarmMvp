# ShiftAlarmMvp

## 프로젝트 개요
ShiftAlarmMvp는 Android Kotlin Compose 기반의 교대근무 알람 앱입니다.  
이 프로젝트의 핵심 가치는 화려한 UI보다, 교대근무자가 실제로 믿고 쓸 수 있는 알람 신뢰성에 있습니다.

- 제품 정체성: 실사용 중심 교대근무 알람
- 현재 단계: MVP를 넘어 실제 사용 흐름과 신뢰도 점검 루프를 갖춘 확장 단계
- 기준일: 2026-03-10

## 현재 상태 요약
- 홈 화면에서 근무 캘린더, 다음 알람, 신뢰도 상태를 함께 확인 가능
- Editor에서 알람 시간/패턴/신뢰도 점검(다음 예약 미리보기, 2분 테스트) 가능
- 배터리/정확 알람/알림 권한 상태를 종합해 신뢰도 상태칩 표시
- 재부팅/시간 변경/날짜 변경/시간대 변경/앱 업데이트 시 자동 복구 루프 동작

## 현재 사용자 흐름
1. 홈에서 오늘 근무와 다음 알람 시각을 확인한다.
2. 패턴 탭에서 근무 패턴(대표근무+직접입력)을 설정한다.
3. 알람 시간(1차/2차)을 시간 카드에서 편집한다.
4. 필요 시 신뢰도 단계로 진입해 권한/배터리 상태를 점검한다.
5. `2분 테스트`로 실제 트리거를 빠르게 검증한다.
6. 캘린더에서 오늘/내일 빠른 선택 후 휴가/스킵 예외를 원탭 적용한다.

## 현재 개발 방향
우선순위는 아래 순서를 고정 기준으로 유지합니다.

## 기술 메모
### 반복 계산 규칙
- 기준일(anchor) 주를 1주차로 간주
- 현재 날짜가 로테이션의 몇 주차 슬롯인지 계산
- 해당 슬롯에 선택된 요일이면 알람 후보
- 가장 가까운 미래 시각을 예약

### 주요 파일
- `app/src/main/java/com/example/shiftalarmmvp/data/AlarmRuleEntity.kt`
- `app/src/main/java/com/example/shiftalarmmvp/scheduler/AlarmTimeCalculator.kt`
- `app/src/main/java/com/example/shiftalarmmvp/ui/MainActivity.kt`

## 다른 장소에서 이어 개발하기
### 1) Git 사용 (권장)
현재 PC:
1. 변경 저장
2. 커밋
3. 원격 저장소로 push

새 PC:
1. 저장소 clone
2. Android Studio에서 프로젝트 열기
3. Gradle Sync
4. `./gradlew.bat :app:assembleDebug`로 빌드 확인

### 2) ZIP/외장디스크 복사 (간단)
1. `ShiftAlarmMvp` 폴더 전체 복사
2. 새 PC에서 Android Studio로 열기
3. 첫 실행 시 Gradle/SDK 재다운로드 후 Sync

권장 제외 항목(복사 용량 절약):
- `.gradle/`
- `build/`
- `app/build/`

### 3) 장비별로 다시 설정되는 항목
- `local.properties` (SDK 경로): PC마다 자동/수동 재생성
- 에뮬레이터(AVD): PC마다 별도 생성 필요
- 앱 내부 데이터(알람 DB): 에뮬레이터를 바꾸면 기본적으로 같이 이동되지 않음

### 4) 새 환경에서 바로 체크할 것
1. 앱 설치/실행
2. 알람 1개를 1분 뒤로 등록
3. 홈으로 나가 백그라운드 상태에서 알람 수신 확인
4. 스누즈/해제 동작 확인
