# ShiftAlarmMvp Icon Generation Guide

## Objective
Create a brand-new icon concept for ShiftAlarmMvp with strong readability at small sizes.

## Required outputs (each variant)
1. 1024x1024 master PNG (with background)
2. 1024x1024 transparent PNG (symbol only)
3. 512x512 transparent PNG
4. 192x192 transparent PNG

## Variants
- Create 3 variants: A, B, C

## Style direction
- Theme: shift rotation + alarm immediacy
- Look: simple geometric vector style
- Background: deep navy `#0B1331`
- Accent colors: blue and amber family only
- Keep symbol centered and dense enough for launcher visibility

## Avoid
- Text, numbers, watermark
- Photo textures
- Very thin lines
- Overly complex gradients/details

## Prompt template (Korean)
모바일 앱 아이콘을 생성해줘. 앱 주제는 교대근무 알람이고, 완전 신규 컨셉으로 3개 시안(A/B/C)을 만들어줘. 스타일은 심플하고 선명한 벡터 느낌, 작은 크기에서도 인지 가능해야 해. 배경은 딥 네이비(#0B1331) 계열, 포인트 컬러는 블루/앰버 계열로 제한해줘. 텍스트, 숫자, 워터마크, 사진 질감은 금지. 각 시안마다 1024x1024 마스터 PNG 1장과 투명 포그라운드 PNG(1024, 512, 192)를 함께 제공해줘.

## Android integration notes
- Use adaptive icon safe center area for foreground symbols
- Maintain high contrast on light/dark backgrounds
- Prepare one simplified monochrome silhouette for themed icons
